LIVE VIDEO TRANSLATOR - CHROME EXTENSION
=========================================

Translate video audio to any language in real-time with optional voice output

FEATURES:
- Real-time audio transcription (auto-detects 99 languages)
- Live translation to 10+ languages
- OPTIONAL: Text-to-speech voice translation (mutes original video)
- Choose between 2 transcription models (Whisper-1, GPT-4o-mini-transcribe)
- 6 different TTS voices (Alloy, Echo, Fable, Onyx, Nova, Shimmer)
- Works on YouTube, Spotify, and all websites
- Draggable overlay interface

COST:
TEXT ONLY MODE (no voice):
- Transcription: ~$0.006-0.015 per minute of audio
- GPT-4o-mini translation: ~$0.0001 per translation
- Total: ~$0.40-0.50 per hour of video

WITH VOICE TRANSLATION:
- Transcription: ~$0.006-0.015 per minute
- Translation: ~$0.0001 per translation
- TTS (GPT-4o-mini-tts): ~$0.60/1M tokens (~$0.01 per 1000 words)
- Total: ~$0.50-0.65 per hour of video

INSTALLATION:

1. CREATE ICON FILES
   - Open: extension/icon-generator.html
   - Download 3 icons (icon16.png, icon48.png, icon128.png)
   - Save to the "extension" folder

2. INSTALL EXTENSION
   - Chrome: chrome://extensions/
   - Enable "Developer mode"
   - Click "Load unpacked"
   - Select: D:\translation_app\extension
   - Done!

3. GET OPENAI API KEY
   - Go to: https://platform.openai.com/api-keys
   - Create new API key
   - Copy the key

4. USAGE
   - Go to YouTube, play a video
   - Click extension icon → "Show Translator"
   - Paste OpenAI API key → Click "Save"
   - Select target language (Gujarati, Hindi, etc.)
   - Choose transcription model (GPT-4o-mini-transcribe recommended)
   - OPTIONAL: Enable "🔊 Voice Translation" to hear translated speech
     - Select voice (Nova recommended for multilingual)
     - Select TTS model (GPT-4o-mini-tts recommended - fastest & cheapest)
   - Click "Start Translation"
   - Watch live transcription + translation appear!
   - If voice enabled: Original video mutes, translated voice plays

HOW IT WORKS:
1. Captures video audio in 3-second chunks (no gaps, no lost audio)
2. Auto-detects spoken language and transcribes (Whisper or GPT-4o-mini)
3. GPT-4o-mini translates to your selected language
4. Displays both original (any language) and translation
5. IF voice enabled: Converts translation to speech, mutes original video

SUPPORTED INPUT LANGUAGES (Whisper auto-detects):
- 99 languages including English, Hindi, Spanish, French,
  German, Japanese, Korean, Chinese, Arabic, Portuguese, etc.

SUPPORTED OUTPUT LANGUAGES (Translation):
- English, Gujarati, Hindi, Spanish, French, German
- Japanese, Korean, Chinese, Arabic, Portuguese
- (Can translate to ANY language via GPT)

VOICE OPTIONS (TTS):
- Alloy: Neutral, balanced tone
- Echo: Male, clear and direct
- Fable: British accent, storytelling
- Onyx: Deep, authoritative male
- Nova: Female, warm and natural (best for multilingual)
- Shimmer: Warm, friendly female

TTS MODELS:
- GPT-4o-mini-tts: Fastest, cheapest ($0.60/1M) - RECOMMENDED
- TTS-1: Standard quality ($15/1M)
- TTS-1 HD: High quality ($30/1M)

TROUBLESHOOTING:
- "No audio/video found": Make sure video is playing
- "Whisper API error": Check your API key and credits
- "Already connected": Refresh page and try again

PERFORMANCE:
- Latency: ~4-6 seconds (3s recording + 1-2s processing)
- API key saved in browser localStorage (secure)
- Skips silent chunks automatically
- Processing time shown in browser console (F12)

TIPS:
- Voice translation is OPTIONAL - leave it off to just see text
- Use GPT-4o-mini-tts for TTS (25x cheaper than TTS-1!)
- Nova voice works great for multilingual content
- Original video automatically unmutes when you stop translation
- Toggle voice on/off anytime without restarting
- Works best with clear audio
- Check console (F12) to see detailed processing logs
- All settings saved automatically (API key, language, voice, etc.)
