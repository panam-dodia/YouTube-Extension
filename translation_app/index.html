How to use:

  1. Click "Start Capture"
  2. Select the browser tab you want to capture audio from
  3. Make sure to check "Share audio" in the permission dialog
  4. The app will visualize and analyze the audio in real-time

Note: This uses the browser's getDisplayMedia API, which requires user permission and HTTPS (or localhost).
